## Objetivo

Que la PWA esté publicada en una dirección pública con HTTPS, se pueda instalar y funcione con la API y la base de
datos de producción.

## Criterios de aceptación

1. La app abre desde cualquier navegador en una URL pública con HTTPS.
2. Cumple los requisitos de instalación de una PWA (manifest, íconos, service worker).
3. Se despliega sola con cada cambio aprobado en `main`.
4. La API y la base de producción responden correctamente a la app.

## Arquitectura del despliegue

| Parte | Servicio | Cómo se despliega |
|---|---|---|
| Front (PWA) | Azure Storage, sitio estático (`$web`) | GitHub Actions `deploy-front.yml` en cada push a `main`: `expo export -p web`, service worker, gzip y subida |
| API | Azure App Service `glamspaces-api` | GitHub Actions `main_glamspaces-api.yml` en cada push a `main` |
| Base de datos | Azure SQL `glamspaces-db` | Scripts `Database/NN_*.sql` corridos a mano por el responsable |
